# Enterprise Agent Security Lab

A hands-on security architecture lab exploring the risks and controls associated with enterprise AI agents.

## Scenario

TheMBank is a fictional financial institution deploying an internal AI agent named Mira.

Mira will eventually interact with synthetic customer data, internal documents, and simulated enterprise tools.

The lab will intentionally introduce security weaknesses into the agent architecture, demonstrate their impact using synthetic data, and then implement and test security controls.

## Objectives

- Build a simple enterprise AI agent.
- Understand AI agent tool use.
- Explore authorization boundaries between users, agents, and tools.
- Demonstrate selected agentic AI attack scenarios.
- Apply security architecture principles to mitigate identified risks.
- Convert security requirements into testable technical controls.

## Disclaimer

This project uses only fictional systems and synthetic data.

Vulnerable implementations are intentionally created for defensive security research and education in a controlled lab environment.
